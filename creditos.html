Fonte de Dados

Todos os dados exibidos neste projeto — incluindo informações sobre Pokémon, estatísticas, habilidades, movimentos, evoluções, tipos, gerações e regiões — são obtidos exclusivamente por meio da PokéAPI, uma API pública e gratuita para dados do universo Pokémon.

Nenhum dado é inserido manualmente. Toda a informação é buscada dinamicamente via requisições HTTP aos endpoints oficiais da PokéAPI (https://pokeapi.co/api/v2/).

Documentação da PokéAPI: pokeapi.co/docs/v2

Imagens

As imagens dos Pokémon exibidas neste projeto são URLs retornadas diretamente pela PokéAPI nos campos sprites de cada Pokémon, incluindo o repositório público de sprites disponibilizado pela PokéAPI (github.com/PokeAPI/sprites).

As imagens de "official-artwork" são obtidas do mesmo repositório público de sprites da PokéAPI. Nenhuma imagem é baixada ou armazenada localmente neste projeto.

Nenhuma imagem é obtida do site oficial da Pokémon Company, do Google Images ou de outras fontes não autorizadas.

Nota: As imagens de Pokémon são propriedade de seus respectivos detentores de direitos. Este projeto as referencia conforme disponibilizadas pela PokéAPI para fins educacionais e de fan project. Não afirmamos que essas imagens possuem licença comercial livre.

Tecnologias Utilizadas

Este projeto foi desenvolvido com tecnologias web padrão:

  • HTML5, CSS3 e JavaScript puro (sem frameworks)
  • PokéAPI — pokeapi.co (dados)
  • Google Fonts — Rajdhani, Share Tech Mono (tipografia)
  • Intersection Observer API (lazy loading)
  • localStorage (favoritos persistentes)
